# Rubric: commit_message

Each line starting with "- " is one criterion the judge grades pass/fail.
Lines containing TODO are skipped. Fill them in before you grade.

- Subject line is 72 characters or fewer and written in the imperative ("Fix ...", not "Fixed ..." or "Fixes ...")
- Body explains WHY the change was needed (slugs must be lowercase / the test expected lowercase), not only what changed
- Contains nothing besides the commit message: no "Here's a commit message:", no markdown fences, no summary of tool calls
- TODO: add a criterion you care about (e.g. mentions the function name, no trailing filler)
